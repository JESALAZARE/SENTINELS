Administración del portal de clientes

Panel de administración

Este panel guarda los datos de tus clientes cifrados directamente en tu repositorio de GitHub. Cada cambio se publica solo y tus clientes lo ven en 1–2 minutos.

¿Cómo creo la llave? (una sola vez)
  1. Entra a github.com/settings/personal-access-tokens/new.
  2. Token name: Portal Sentinels. Expiration: 1 año (o la que prefieras).
  3. Repository access: Only select repositories → SENTINELS.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Clic en Generate token, cópiala y pégala arriba. GitHub solo la muestra una vez.
La llave se guarda únicamente en este navegador. Si se te pierde o vence, crea otra igual.

¿Prefieres trabajar sin conexión? Usar la carpeta local (tendrás que publicar con Commit + Sync).

Configuración inicial

Crea la contraseña de administrador. Con ella abres este panel y puedes ver y editar a todos los clientes.

Usa una frase larga (mínimo 14 caracteres) y guárdala en un lugar seguro. Si la pierdes no se puede recuperar y tendrías que volver a crear a los clientes.

Acceso creado

Envía estos datos al cliente. Esta contraseña solo se muestra ahora; si se pierde, usa “Nueva contraseña”.

Aplicar solicitud de contraseña

Cuando un cliente cambia su contraseña desde el portal, te llega un correo de Formspree con un campo request_code (empieza con SPREQ1:). Cópialo completo y pégalo aquí. La contraseña nueva viene cifrada: ni tú ni nadie puede leerla.
